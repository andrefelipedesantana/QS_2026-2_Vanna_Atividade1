# Qualidade de Software 2026.2 — AV1 — Projeto Vanna

Atividade avaliativa (AV1) da disciplina de Qualidade de Software, com foco na especificação e avaliação inicial da qualidade de uma aplicação de IA generativa.

## Sobre a atividade

O objetivo é avaliar se uma aplicação de IA generativa é adequada, confiável e segura para seu contexto de uso, considerando que ela pode produzir respostas plausíveis, porém incorretas, variáveis ou não fundamentadas. Para isso, a equipe vai levantar requisitos verificáveis, aplicar a ISO/IEC 25010:2023, montar casos de teste, coletar evidências e propor um plano de melhoria para o projeto escolhido.
